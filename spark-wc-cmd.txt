APACHE SPARK DEPLOYMENT ON HDFS
================================

1. CHECK JAVA

java -version

If Java is not installed:
sudo apt update
sudo apt install default-jdk -y


2. CHECK SCALA

scala -version

If Scala is not installed:
sudo apt install scala -y


3. DOWNLOAD AND INSTALL SPARK

Download a Spark version compatible with your Hadoop version from:
https://spark.apache.org/downloads.html

Then run:

cd ~/Downloads
tar -xzf spark-*.tgz
sudo mv spark-* /usr/local/spark


4. SET SPARK PATH

echo 'export SPARK_HOME=/usr/local/spark' >> ~/.bashrc
echo 'export PATH=$PATH:$SPARK_HOME/bin' >> ~/.bashrc
source ~/.bashrc


5. VERIFY SPARK INSTALLATION

spark-shell

To exit Spark Shell, type:
:quit


WORD COUNT PROGRAM USING SPARK
==============================

1. CREATE INPUT FILE

echo "hello spark hello hadoop spark" > input.txt


2. START SPARK SHELL

spark-shell


3. ENTER THESE COMMANDS ONE BY ONE IN SPARK SHELL

val input = sc.textFile("input.txt")

val counts = input.flatMap(line => line.split(" "))

val result = counts.map(word => (word, 1)).reduceByKey(_ + _)

result.saveAsTextFile("output")

:quit


4. DISPLAY OUTPUT

cat output/part-00000

EXPECTED OUTPUT

(hello,2)
(spark,2)
(hadoop,1)
